# Lujing Xi — Data · Product · AI

Personal data science blog and portfolio powered by GitHub Pages + Jekyll.

Live site: https://lujinglucyxi.github.io

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Add a post

Create a Markdown file in `_posts/`:

`YYYY-MM-DD-your-title.md`

Use front matter:

```yaml
---
layout: post
title: "Your title"
category: Product Analytics
read_time: 6
description: "A short description."
---
```
